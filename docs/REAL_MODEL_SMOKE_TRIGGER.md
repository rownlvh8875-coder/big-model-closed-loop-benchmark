# 공식 대형 ONNX 체크포인트 연속 5스텝 테스트

2026-11-09: MD-V3 1스텝 공식 ONNX 런타임 추론에 성공한 후, 동일 실행기를 대상으로 **MD-V3와 Light Speed 2 모델 각각 5스텝**을 검증한다.

- 공식 Hugging Face 체크포인트를 다운로드하고 고정 SHA256을 확인한다.
- `new_img` 2채널 영상 모델 입력 및 재귀 `state_*` → `next_state_*`를 매 스텝 실제 그래프에 전달한다.
- 모델 곡률·가속도로 가상 에이전트 위치를 갱신하고 변경된 위치에서 다음 도식적 영상을 생성한다.
- 실패 시 해당 모델에서 중단하고, CD210을 로드하거나 대체 모델 결과를 생성하지 않는다.

**검증 한계:** 실제 comma 카메라 내부/외부 보정과 렌더링 품질은 재현되지 않은 합성 영상이며, 모델 출력의 물리적·주행적 의미, 모델별 우열 및 실제 도로 안전성을 평가하지 않는다. 순수 'ONNX 경로의 기술적 연결' 시험에만 사용한다. 실제 차량 테스트와 차량별 성능 모델링은 없다.
