## Failure protocol fixed before native execution

Complete receipts require all planned rows/captures/parent audits and original
controls. Strict expansion PASS requires every planned field/step exact in
both complete processes. Missing fields, stale summaries, reused UUIDs/nonces,
wrong model/config/runtime/clock/task/bin/guard data and nonfinite values fail.

The public loop captures and infers before evaluating lane truth. Its actual
serialized error string prefixed `LaneTruthError: ` or `RouteContractError: `
may therefore accompany m completed
rows and m+1 successful capture/parent audit records. Save **all** of them, the
original error, actual native exit status and unchanged requested steps before
wire validation. Never truncate the dangling audit or zip it out of evidence.

A data-collection job may preserve a **valid failed diagnostic** only when:

- The unchanged public loop itself returned the exact serialized error type
  prefix above, after at least one completed row and before requested
  completion; provenance explicitly records that public return.
- There is exactly one extra successful capture and inference/audit, with
  source/warp/actual-I420/action/all states/entry pose and clocks retained.
- All normal model/runtime/state reset/clock/two-tick/task/bin/guard/provider
  close/restoration controls validate; no outer setup/close/policy error exists.
- Native status2 is retained as2 and classified VALID_FAILED_DIAGNOSTIC. It
  never becomes a strict PASS. A full receipt with status2, partial with status0,
  or partial with cleanup5 is invalid. Status0/cleanup5 requires a fresh full
  validated receipt; every other status/error remains infrastructure failure.

A valid partial always fails that case's full expansion gate with reason
INCOMPLETE_REQUESTED_EPISODE and a separate first_incomplete_step=m+1. Optional
prefix analysis cannot satisfy the full gate. Do not call compare_fresh_trials
on a partial receipt. Malformed/unexpected/setup/zero-row failures remain CI
failures with raw/log/ledger artifacts retained; no automatic retry.
