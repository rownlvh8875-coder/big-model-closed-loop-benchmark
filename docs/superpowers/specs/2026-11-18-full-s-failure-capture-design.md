# Bounded full-S failure recording preparation

User approved preparing the next cloud diagnostic autonomously. No model or
native simulator is executed, downloaded or activated in this task. Reuse the
isolated worktree, branch from349c270, and implement inline with one final fresh
review. No main merge or environment publication.

Build a separate CPU observer around the existing `run_full_s` function. Do not
edit the original camera, rectifier, policy, adapter, plant, traversal protocol,
native producers, old workflows/requests or existing evidence. The observer
forwards exactly one original capture and the original pair objects. Existing
progress events snapshot parent recurrent state before/after the original step;
no policy wrapper, extra inference/reset, renderer operation or GT control.
Restore the camera's empty raw observer in finally; reject an occupied hook.

Retain first step plus last8 steps (at most9 distinct packages), including any
pending inference. Keep all600 bounded step hash receipts. Each retained step
has existing964×604 road/wide source RGB, original512×256 canvas RGB, derived
uint8[2,6,128,256] I420, typed pre/post states and actual FP32 raw action. Bind
derived input to the parent's actual feed SHA only after a committed step.
Hash all recurrent arrays exactly as the existing audit. A failed inference
retains its pre-state and unknown outcome; never invent post-state or0calls.
There are no extra post-departure steps: 'after' means resulting state at stop.

MD-V3 state shapes/dtypes are pinned by existing spec: state_img_q uint8,
state_desire_q/state_feat_q float32. A complete step payload is25,391,024bytes.
Observer buffer accounting uses12packages +4MiB ledger <320MiB; this excludes
native/model-owned memory and Python allocator overhead, not a whole RSS bound.
Final output cap320MiB including report(max8MiB)/manifest(max4MiB). Require
384MiB free output space before observation (64MiB reserve). Eight hypothetical
private trials reserve3GiB conservatively, not executed here. Keep files in
memory until after the original episode; no ring file deletion. Resource or
observation failure remains explicit incomplete diagnostic, never rescued PASS.

Caller supplies measured lens intrinsics; their provenance is not independently
attested. The receiver independently rewarps retained source RGB, repacks I420,
checks typed bytes/SHA, first/last selection, original report association,
per-step input/action/state receipts and consecutive state continuity. Reject
missing/swapped/duplicate/oversized/symlink/traversal/nonfinite or corrupt data.
Only canonical locally created files; no pickle, ZIP extraction or code import
from evidence. No origin/hardware/physical/CARLA/full-S qualification is earned
by a structurally valid sidecar. Existing failed cohort0/4 remains unchanged.

CLI exposes `plan` and `verify` only, cold help under-I-S. No native-run mode,
workflow trigger, model download or auto-activation. Documentation shows library
integration after existing parent/platform/resource/admission guards, and the
limitations of observer timing/allocation and source-reconstructed feeds. The
unobservable separate full-S cloud task is not duplicated.

Approaches: use existing CPU source hook plus progress events. Retaining all600
full pre/post arrays would require~14GiB/trial; rerender/reinfer would change the
experiment. First+bounded tail preserves the useful onset/failure neighborhood
within the fixed cap. Reuse existing packing/rectifier/audit semantics; older
first-divergence collector's four-step/convergence protocol is not repurposed.
