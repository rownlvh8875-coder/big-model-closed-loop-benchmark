## Interface and trust

`derive_wheel(source: bytes, *, expected_source_sha256: str, expected_metadata_sha256: str, deadline: float) -> tuple[bytes | None, dict]` is a pure in-memory, stdlib-only function. No CLI, filesystem/network/process IO, package imports, environment mutation or import-time action. Exact immutable bytes input and caller-provided lowercase64hex pins are required. Match means caller-pin byte equality only; source origin/API/Git/implementation authentication is not performed. Return native_admission=False, execution_authorized=False, image_preparation_ready=False, official_distribution=False, source_origin_authenticated=False on every result. Future authenticated source/artifact adapters must independently bind the transform implementation and genuine original/derived hashes; a policy hash is not implementation authentication.

Success returns derived bytes and status METADATA_DERIVATIVE_CREATED/complete=True with actual source/metadata/derived SHA256, policy ID/hash, expected upstream filename, derived filename, preserved-member aggregate/count/bytes, input/output byte counts, uncompressed bytes read and elapsed time. Failure returns None, FAILED_OR_INCOMPLETE/complete=False, no derived hash or preserved-complete claims, bounded fixed error_code/failure_stage/counters. External exception text/content/path is never persisted. KeyboardInterrupt/SystemExit propagate. There are no owned filesystem artifacts to clean up.

## Exact policy

Source distribution Name/Version remain metadrive-simulator/0.4.3. Require Metadata-Version2.1 and the exact unconditional header `Requires-Dist: opencv-python` once; reject pre-existing headless/contrib variants and conditional/versioned/folded OpenCV changes. Replace only that header with `Requires-Dist: opencv-python-headless==5.0.0.93`, preserving all other original METADATA bytes, including body, license and other dependency declarations. The original METADATA SHA must match its caller pin.

Source WHEEL requires unique Wheel-Version1.0, Root-Is-Purelib true, Tag py3-none-any, nonempty Generator and no Build/unknown fields. Only LF UTF-8 metadata with a header/body separator is supported; WHEEL has no nonempty body. Replace Generator with `engine-clock-wheel-derivative (metadata-v1)` and append Build1headless. Output filename is `metadrive_simulator-0.4.3-1headless-py3-none-any.whl`; version remains0.4.3 for the fixed identity contract. The build tag, generator and mandatory provenance mark it as a derivative. The tool does not attest runtime compatibility from this label.

Only `metadrive_simulator-0.4.3.dist-info/METADATA`, WHEEL and RECORD may change. Add exactly one new `ENGINE_CLOCK_DERIVATION.json` under that dist-info directory. Every other original member, including runtime, assets, license files and entry points, preserves uncompressed bytes and create_system/external_attr semantics. No original member is deleted. A pre-existing derivation marker, foreign dist-info, RECORD.jws or RECORD.p7s rejects: signatures are never silently dropped or represented as retained validity. License bytes remain untouched; no legal/endorsement assurance is claimed.

Provenance contains fixed policy/build/nonofficial fields, measured source/metadata/WHEEL hashes and the original preserved-member aggregate/count/bytes. No clock, paths, host state or secret values enter output bytes. Policy canonical JSON uses sorted compact ensure_ascii UTF-8; its hash describes policy data only. Preserved aggregate streams sorted canonical descriptors `{path,kind,nbytes,sha256,create_system,external_attr}` plus LF, excluding only the three mutable files. Directories contribute empty-content descriptors. A complete source RECORD covers every regular member with exact SHA256 URL-safe-base64-without-padding and canonical decimal size, except its own empty hash/size row. Reject duplicate/missing/extra/invalid rows. Rebuild derived RECORD from actual written bytes; its own row has empty hash/size. Directories are not RECORD files.

Output is deterministic for identical source/pins/policy: sorted members, timestamp1980-01-01, ZIP_STORED, preserved attributes, canonical provenance and LF CSV RECORD. Container compression/timestamps/order differ from upstream; payload identity is explicitly uncompressed member bytes/attributes, not archive-byte identity. Future outer receipts bind actual transform source and outputs separately.

## Hostile input and resources

Input<=64MiB; at most20000members including the new provenance slot; expanded total<=256MiB; each regular file<=64MiB; each of the three mutable metadata files<=1MiB; output<=512MiB; uncompressed read budget<=512MiB; paths<=4096UTF-8bytes. Read member bodies in<=1MiB chunks, checking budgets/deadline before chunks. No extraction or execution. Pure memory implementation may use hundreds of MiB on a real input; feasibility is not measured and this helper is not the future multi-GiB image transport.

Accept canonical relative POSIX names with no NUL/control, backslash, colon, absolute/dot/dotdot/empty components, duplicate file/directory paths or file ancestors. Only regular files/directories; reject symlink/device/FIFO/socket modes, inconsistent directory metadata, encrypted/unsupported flags/compression. Support classic single-disk ZIP_STORED/DEFLATED only, no ZIP64, data descriptors, extras, per-entry/archive comments or preamble/trailing/hidden gaps. Verify local/central name, flags, compression, CRC and sizes, contiguous layout and EOCD counts/offsets. STORED requires compressed=expanded size. Bounded raw DEFLATE decoding requires a completed stream, no unused/trailing input and exact expanded size/CRC (including empty members); decoded contents also match RECORD. Reserve the canonical new provenance filename against pre-existing file/directory/descendant paths before creating output. Unsupported legitimate packaging fails closed rather than broadening this policy automatically. Actual upstream WHEEL/layout compatibility remains unmeasured until separately gated real preparation.

Deadline is finite absolute perf_counter, exact int/float not bool, capped at start+180s. This is cooperative CPU checking on bounded immutable in-memory data, not a POSIX signal timer or hard realtime claim. Invalid/expired deadlines and all failures return no output; a completion after deadline cannot stay complete. Tests may lower only new-module caps to exercise failure. No input is mutated and no partially derived bytes escape on failure.
