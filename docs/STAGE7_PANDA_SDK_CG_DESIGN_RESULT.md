# Cg-aware SDK repair design and pinned inputs

The repair design and next implementation plan are concrete. This phase **did not build a candidate, change the current SDK/image, or run native Panda/GLX**. The confirmed112-byte GSG field-layout incompatibility is not yet repaired; the earlier SIGABRT's exact cause remains unconfirmed. Scientific result remains strict0/4 FAIL;Stage7 INCOMPLETE.

Selected approach: retain the installed Panda wheel and its modules, build a separate Cg-aware SDK candidate, and require independent checks of the actual binary/compile-only descriptor before calling it statically ready. Full Panda rebuild is a separate alternative, not an automatic fallback. The static pass must match major0x688,minor0x68c,vendor0x670; merely adding a flag, matching vtables or producing success JSON cannot pass. This is selected-layout evidence, not full object ABI or a crash-fix certificate.

NVIDIA Cg3.1 original headers were acquired over verified HTTPS. The24829131-byte archive is pinned to SHA256 e8ff01e6cc38d1b3fd56a083f5860737dbd2f319a39037528fb1a74a89ae9878. Only cg.h/cgGL.h are proposed build inputs. Toolkit versus installed Cg/CgGL whole files differ, but their selected .text/.rodata hashes match. The design uses the **current authenticated-image libraries**, never toolkit/example Trace DSOs. These limited comparisons do not independently prove header ABI identity or a publisher signature. Archive/headers remain output-only; Git contains provenance, hashes and analysis recipes.

The old parser-inc/Cg files explicitly prohibit compilation; the design rejects them. The actual makepanda option is --use-nvidiacg with explicit nvidiacg/cggl include/library paths. Old source/sysroot/build/header trees remain unchanged. Current local free space is below the8GiB build allowance, so the candidate plan uses a fresh ubuntu-24.04 hosted runner and explicit GCC13 with a new measured profile. It does not reuse the old GCC14 tool hash profile, claim bit reproducibility, or isolate Cg as the sole experimental variable. Missing tools/input/disk preflight stops without an implicit package install or compiler fallback. An OCI compiler alternative was inspected as metadata only and was not pulled or selected.
