## 실제로 확인한 데이터 흐름

1. MetaDrive가 가상 도로에서 **일반 및 광각 RGB 카메라 이미지**를 각각 생성
2. 별도 검증된 가상 핀홀 내부 파라미터를 이용하여 **512×256 모델 화면**으로 워프
3. RGB → I420 → 6평면 패킹으로 ONNX의 **(2,6,128,256) uint8 영상 입력** 생성
4. 실제 MD-V3 ONNX Runtime 추론 수행; 그래프의 **state_* 입력과 next_state_* 출력**을 연결
5. 원시 모델 action의 횡가속도 → 목표곡률(1/m), 종가속도(m/s²) 추출
6. 모든 모델에 공통인 **이상적 운동학**으로 가상 위치·방향·속도를 갱신
7. 새 가상 카메라 위치에서 다음 RGB 화면을 생성하고 위 과정 반복

이 시험은 **carrotpilot MPC, 차량별 조향·제동/타이어·EPS 동역학, CD210 폴백 또는 실차 CAN**을 사용하지 않았다.

## 광학 내부 파라미터 확인

같은 MetaDrive 0.4.3을 사용한 사전 [RGB 렌더링 시험 42569322601](https://github.com/rownlvh8875-coder/big-model-closed-loop-benchmark/actions/runs/42569322601)에서 확인:

- 일반 렌즈 기준 fx=1324 px, 측정 fx≈1323.999864 px
- 광각 렌즈 기준 fx=283.5 px, 측정 fx≈283.500033 px
- 512×256으로의 디지털 워프 유효 소스 영역: 일반 99.609375%, 광각 100%
- 별도 [영상 → 실제 ONNX 입력 텐서 검증 42569804426](https://github.com/rownlvh8875-coder/big-model-closed-loop-benchmark/actions/runs/42569804426)에서 **shape=(2,6,128,256), dtype=uint8**, 두 시야의 독립성 및 가상 위치 변화에 따른 텐서 변화 확인

이는 가상 핀홀 렌즈의 **설정값과 읽기값의 일치** 및 모델 입력 파이프라인의 정확한 형상 검증이다. 실제 comma 광각의 비선형 렌즈 왜곡까지 검증한 것이 아니다.

## 아직 입증되지 않은 것

- **실제 comma 카메라 광학과의 정합성**: 렌즈 왜곡, 센서 외부 캘리브레이션, 자세 축/부호 및 투영 오차, 시간 동기화, RGB→NV12 색채/보간 정밀도
- **메타드라이브 도로 정답과 카메라 자세의 공간적 일치**: 독립 3D 랜드마크의 픽셀 재투영 오차 미측정
- **대형모델 주행성능**: S자 코너 커팅, 실제 도로 차선 이탈률, 차량 간 거리, 정상 감속/정지 판단, 모델 간 순위
- **장시간 안정성**: 3스텝만 실행했으며 재귀 상태를 오랫동안 유지한 성능·신뢰도는 미검증
- **실시간 추론**: CPU 추론 지연은 모형의 0.05초 가상 시간 주기보다 길다. 결정적 가상시간과 처리시간을 분리하여 측정한다.

**차선 침범·모델 성능 점수는 산출하지 않았으며, 가상 주행모델의 비교 결과를 실제 차량 주행 안전성으로 해석하지 않는다.**
