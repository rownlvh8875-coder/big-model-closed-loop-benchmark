## 재현

게시된 파일은 아래 명령으로 검증합니다. GitHub PDF 뷰어와 저장한 HTML은 같은 요약을 제공합니다.

```bash
cd docs/evidence/sdk3-model-comparison-20261125
sha256sum -c SHA256SUMS
python -B score.py comparison.json
```

자세한 실행 절차는 [비교판 재현 문서](../../SDK3_BENCHMARK_COMPARISON.md)에 있습니다. 원본 기록을 보유한 경우 Python 3.11, NumPy 2.4.6, opencv-python-headless 5.0.0.93 환경에서 아래와 같이 원본 파일 4,284개를 대조하고 새 HTML·JSON을 생성할 수 있습니다. 원본 루트에는 `inputs/` 폴더가 있어야 합니다. [원본 파일 해시 목록](inputs.SHA256SUMS)은 보관된 자료를 정확히 식별합니다.

```bash
bash rebuild.sh /path/to/retained-input-root /path/to/venv/bin/python /path/to/new-report
```

보고서 재현은 기존 입력을 읽습니다. 대용량 원본 캡처와 전체 실행 로그는 기존 보관본에 있으며, 이 폴더는 검증된 비교 결과와 원본 확인용 해시를 담고 있습니다.

- [전처리 비교 · Actions 44711162968 attempt 1](https://github.com/rownlvh8875-coder/big-model-closed-loop-benchmark/actions/runs/44711162968/attempts/1)은 원본 ZIP을 받아 오프라인 검증했습니다. 모델 실행 8건, 실제 추론 1,513회였고 모두 차선 침범으로 종료했습니다. RGB를 먼저 처리하는 방식과 RGB에서 만든 YUV를 먼저 처리하는 방식의 첫 입력과 첫 조향이 달라졌습니다. 변환 순서와 샘플링 규칙을 함께 바꾼 시험이며, 조건별 A/B 한 번씩의 실행이므로 엄격 반복 판정은 없습니다.
- 첫 Linux Cloud 시도에서는 동결 런타임 아티팩트 수신이 HTTP 403으로 차단돼 모델·추론 0건이었습니다. 나중에 받은 [동결 SDK3 이미지의 원본 Actions](https://github.com/rownlvh8875-coder/big-model-closed-loop-benchmark/actions/runs/43700449423) ZIP은 크기와 SHA-256을 별도로 확인했습니다.
- Windows 노트북의 무모델 카메라 4/4 통과는 별도 현지 보고입니다. Windows 공식 모델, 실측 광학, 센서 NV12 검증은 미검증이며 실제 CARLA 교차검증은 미실행입니다.

## 추가로 할 시험

1. **모델 범위 확대.** 같은 텐서 규격인 미실행 6개는 공식 파일 해시와 조향·가속 해석을 확인한 뒤 같은 조건에 등록합니다. N16과 `26ada517`은 입력·출력 의미를 별도로 확인하고, 호환성을 입증한 조합을 판정합니다.
2. **진출 램프의 실패 원인 확인.** Fairy Tale이 기존 진출 두 조건에서 첫 침범한 위치를 기준으로 독립적인 도로 배치와 시작 속도를 더합니다. 한 번에 조건 하나를 변경하고, 첫 차선 침범과 경로 진행 거리를 같이 비교합니다.
3. **종방향 반복과 추가 변형.** 현재 각 모델·조건은 1회입니다. 독립 반복과 새로운 초기 차간 거리·접근 속도를 추가한 뒤, 최소 간격·최소 TTC·정지와 재출발·가속 변화율을 같은 기준으로 비교합니다.
4. **교차 엔진은 선택 검증.** 전용 CARLA 환경이 있으면 MetaDrive와 대응하는 코스를 먼저 확인하고, 같은 종료 기준으로 성능 변화를 엔진별로 보고합니다.

새 실험의 코스와 점수 기준은 실행 전에 고정합니다. 공개 모델 파일을 추가할 때 호환성 검사나 짧은 준비 실행의 결과를 19조건 완주 성적으로 집계하지 않습니다.
