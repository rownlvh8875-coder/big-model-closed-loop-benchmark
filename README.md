# 병합 완료 브랜치 보관 · 2026-11-26

원래 브랜치 이름과 전체 커밋 SHA, 병합된 PR 번호를 branches.tsv에 기록했습니다. 원본 브랜치의 모든 커밋은 이 태그의 이력에서 도달할 수 있습니다.

22개 모두 병합 PR의 최종 커밋이 정리 시점의 브랜치와 같았습니다. 6개는 원본 커밋이 직접 기본 브랜치의 이력에 있고, 16개는 PR의 변경을 합친 커밋의 파일 트리가 원본 변경을 적용한 결과와 일치합니다.

복구가 필요하면 보관 태그를 가져와 branches.tsv에서 대상 커밋 SHA를 확인한 뒤 로컬에서 해당 SHA로 브랜치를 만들 수 있습니다.
